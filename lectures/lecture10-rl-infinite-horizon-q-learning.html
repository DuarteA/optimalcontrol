Reinforcement learning formulation

Dynamic model

  • None! Only the real system or a simulator which can be ran is available.
  • Still, for analysis, a model taking the form \(x_{k+1} = f(x_k,u_k,w_k)\) is subsumed, where \(w_k\) are the disturbances.

Reward/Cost function

  • Encapsulates the goals to be achieved in the problem. Obtained through the agent’s interaction with the environment/simulator.
  • Additive over time \(\sum_{k=0}^{h-1}g_k(x_k,u_k)+g_h(x_h)\). Typically in the literature it should be maximised. However, we will consider that it should be minimized.

Goal

  • Find a control policy (function from states to actions) which minimizes the cost based on data (trial and error).

Approaches in RL

Approximations in value space

  • Approximate the optimal cost-to-go \(J_{k+1}^\star\) by some other cost \(\tilde J_{k+1}\) and use the policy

\[u_k = \underset{u_k \in U_k(x_k)}{\arg\min} \ \mathbb{E}\big[g_k(x_k,u_k,w_k)+\tilde J_{k+1}(f_k(x_k,u_k,w_k))\big]\]

(this is for a 1-step lookahead horizon; there are also multistep variants)

  • Typically \(\tilde J_{k+1}\) is taken from a given parametric class of functions \(\tilde J_{k+1}(x_{k+1},r_{k+1})\), with parameters \(r_{k+1}\) obtained from training data.

Approximations in control/policy space

  • Select the policy from a parameterized class of policies (e.g. state feedback, neural network)

\[u_k = \mu_k(x_k,r_k)\]

  • Involves search in the parameter space; the utility of each parameter is assessed via simulation. Typically one parameterizes the policy \(\tilde\mu_k(x_k,r_k)\) and uses a gradient method to search for parameters that lead to a small overall cost.

Approximation in value and control/policy spaces

  • Combination of the two previous ones.

Parametric cost approximation

Parameterization of \(\tilde J_{k+1}\): typically using a neural network in model-free settings.

The network weights are trained (optimized) based on simulation outputs \(x_{k+1}^s\), \(s\in\{1,2,\dots,N\}\) of the desired output \(\tilde J_{k+1}(x_{k+1}^s)\) for the input \(x_{k+1}^s\), aiming to minimise the fitting error \(e\).

Overview

  • We will first introduce concepts for finite state and control spaces, where we can actually use reinforcement learning to obtain optimal policies.
  • We then move to continuous state spaces, where we need to approximate the value function (e.g. with a neural network) and still search over discrete actions.
  • Finally, we will consider continuous state and control/action spaces.

Infinite horizon problems

  • We have been focussing on finite horizon problems, where policies are time-varying \(u_k=\mu_k(x_k)\).
  • When the horizon is infinite (e.g. LQR) we typically get simpler time-invariant policies \(u_k=\mu(x_k)\).
  • There are 4 infinite horizon problems, all considering a time-invariant model and running cost.

Infinite horizon problems

All four consider the same time-invariant model

\[x_{k+1}=f(x_k,u_k,w_k) \qquad k \in \{0,1,2,\dots\}\]

Undiscounted  ·  \(\sum_{k=0}^{\infty}\mathbb{E}\left[g(x_k,u_k)\right]\)

Running cost will eventually approach zero – infinite-horizon LQR.

Stochastic shortest path  ·  \(\sum_{k=0}^{\infty}\mathbb{E}\left[g(x_k,u_k)\right]=\mathbb{E}\left[\sum_{k=0}^{T-1}g(x_k,u_k)+\underbrace{g(x_T,\cdot)}_{=0}\right]\)

System eventually reaches a special terminal state \(x_T\) where it stays with zero cost.

Discounted  ·  \(\sum_{k=0}^{\infty}\mathbb{E}\left[\alpha^kg(x_k,u_k)\right]\)

Discount makes sure the cost is always bounded – example given later.

Average cost  ·  \(\lim_{T\to\infty}\frac{1}{T}\mathbb{E}\left[\sum_{k=0}^{T-1}g(x_k,u_k)\right]\)

Averaging makes sure the cost is bounded, e.g. LQG; not considered further, see appendix.

Shortest path problems

In many problems the dynamics and the cost do not depend explicitly on time

\[x_{k+1}=f(x_k,u_k,w_k) \qquad k \in \{0,1,2,\dots\}\]

\[\mathbb{E}\left[\sum_{k=0}^{T-1}g(x_k,u_k)\right] \qquad\qquad \text{Prob}[w_k=\ell]=p_\ell^{x_k,u_k}\]

Besides, the system evolves for an undetermined time \(T\), which can be arbitrarily large, until a certain set of terminal states \(\mathcal{X}\) is reached, \(x_T\in\mathcal{X}\).

Then we can consider that the cost is an infinite-horizon cost

\[\sum_{k=0}^{\infty}\mathbb{E}[g(x_k,u_k)]\]

and that \(x_k \in \mathcal{X} \implies x_{k+1}\in\mathcal{X}\) and \(x_k\in\mathcal{X} \implies g(x_k,j)=0,\ \forall j\), since then

\[\sum_{k=0}^{\infty}\mathbb{E}[g(x_k,u_k)] = \mathbb{E}\left[\sum_{k=0}^{T-1}g(x_k,u_k)+\underbrace{g(x_T,\cdot)}_{=0}\right]\]

Finite horizon problems as shortest paths

A finite horizon problem (even time-varying!) can be seen as a shortest path problem

\[\min_{u_k=\mu_k(x_k)} \mathbb{E}\left[\sum_{k=0}^{h-1}g_k(x_k,u_k)+g_h(x_h)\right] \qquad x_{k+1}=f_k(x_k,u_k,w_k)\]

If we consider the augmented state to be \(\bar x_k = (\bar x_{1,k},\bar x_{2,k}) = (x_k,k)\) we can write

\[\bar g(\bar x_k,u_k,w_k)=\begin{cases} g_{x_{2,k}}(x_{1,k},u_k) & \text{if } 0\leq x_{2,k}\leq h-2\\ g_{h-1}(x_{1,h-1},u_k)+g_h(f_{h-1}(x_{1,h-1},u_{h-1},w_{h-1})) & \text{if } x_{2,k}=h-1\\ 0 & \text{if } x_{2,k}\geq h \end{cases}\]

Note that the optimal policy \(\mu(\bar x_k)\) only depends on the state and not on time. However, since time is part of the state \(\bar x_k\), we do recover the previous class of policies.

Example: Pac-man

Find the optimal policy for the ghost to catch Pac-man in minimum time. Shortest path problem, with terminal states (Pac-man and ghost occupy the same cell).

State \(\quad x_k=(x_{1,k},x_{2,k})\)

  • \(x_{1,k}\in\{1,2,\dots,77\}\) – Pac-man’s cell
  • \(x_{2,k}\in\{1,2,\dots,77\}\) – ghost’s cell

Model \(\quad x_{k+1}=f(x_k,u_k,w_k)\)

  • \(u_k\) – ghost decision; \(w_k\) – possible uncertainty in Pac-man’s moves
  • must enforce \(x_{1,k}=x_{2,k} \implies x_{1,k+1}=x_{2,k+1}\)

Cost \(\quad \sum_{k=0}^{\infty}\mathbb{E}[g(x_k,u_k)]\)

\[g(x_k,u_k)=\begin{cases}1 & \text{if } x_{1,k}\neq x_{2,k}\\ 0 & \text{if } x_{1,k}=x_{2,k}\end{cases}\]

Transition probability model

We focus now on discrete optimisation problems.

Recall that we can always write the model \(x_{k+1}=f_k(x_k,u_k,w_k)\) in terms of transition probabilities

\[p_{ij}(\ell)=\text{Prob}[x_{k+1}=j\mid x_k=i,\ u_k=\ell]\]

In this case the model is simply

\[x_{k+1}=w_k \qquad \text{with} \qquad \text{Prob}[w_k=j\mid x_k=i,\ u_k=\ell]=p_{ij}(\ell)\]

The running cost in \(\mathbb{E}\left[\sum_{k=0}^{\infty}g(x_k,u_k)\right]\) (or other cost versions) remains the same if it only depends on state and inputs; if it also depends on disturbances it is adjusted to

\[g(i,u)=\sum_j p_{ij}(u)\tilde g(i,u,j)\]

Assumptions

  • The state belongs to one of \(n\) states plus a terminal state \(t=n+1\), \(x\in\{1,2,\dots,n+1\}\).
  • Once the state reaches the terminal state it remains there with no cost, i.e. for every \(u\)

\[p_{n+1,n+1}(u)=1 \qquad g(n+1,u)=0\]

(several terminal states can be modelled by setting a transition from each terminal state to \(t\))

  • Regardless of the initial state and policy, there is a positive probability that \(t\) is reached after a finite fixed number of stages.

Value iteration: shortest path

Algorithm to obtain the optimal value function (cost-to-go), which is the solution to the Bellman equation (see next slide).

Value iteration algorithm

Given any initial conditions \(J_0(1),\dots,J_0(n)\) run the iteration for \(k\in\{0,1,2,\dots\}\)

\[J_{k+1}(i)=\min_{u\in U(i)}\Big[g(i,u)+\sum_{j=1}^{n}p_{ij}(u)J_k(j)\Big] \qquad i\in\{1,\dots,n\}\]

This will converge to some values \(J^\star(i)\) (solution to the Bellman eq.); thus, one can stop when

\[\max_{i\in\{1,\dots,n\}}|J_{k+1}(i)-J_k(i)|<\epsilon\]

This is exactly the DP algorithm with different indexing, since the number of iterations until one stops is unknown. If the number of iterations is fixed to \(h\) one can start with \(J_h(1),\dots,J_h(n)\) and run

\[J_{k-1}(i)=\min_{u\in U(i)}\Big[g(i,u)+\sum_{j=1}^{n}p_{ij}(u)J_k(j)\Big]=\min_{u\in U(i)}\mathbb{E}_w\big[g(i,u)+J_k(f(i,u,w))\big]\]

Bellman equation: shortest path

The values \(J_k(1),\dots,J_k(n)\) of the value iteration algorithm converge to the solution of the Bellman equation. However, this nonlinear equation admits a solution which can also be obtained by other methods.

Theorem

Under the underlying assumptions, the following set of nonlinear equations

\[J^\star(i)=\min_{u\in U(i)}\Big[g(i,u)+\sum_{j=1}^{n}p_{ij}(u)J^\star(j)\Big] \qquad i\in\{1,\dots,n\} \qquad \text{(Bellman equation)}\]

admits a unique solution.

Optimal policy: shortest path

The optimal policy can be obtained from the solution to the Bellman equation (since value iteration provides this solution asymptotically, it also provides the optimal policy).

Theorem

The minimiser in the Bellman equation

\[\mu(i)=\underset{u\in U(i)}{\arg\min}\Big[g(i,u)+\sum_{j=1}^{n}p_{ij}(u)J^\star(j)\Big] \qquad i\in\{1,\dots,n\}\]

where

\[J^\star(i)=\min_{u\in U(i)}\Big[g(i,u)+\sum_{j=1}^{n}p_{ij}(u)J^\star(j)\Big] \qquad i\in\{1,\dots,n\}\]

is an optimal policy for the shortest path problem \(x_{k+1}=w_k\), \(p_{ij}(\ell)=\text{Prob}[w_k=j\mid u_k=\ell,\ x_k=i]\).

Discounted cost as a shortest path

Given the original discounted cost problem \(\ \mathbb{E}\left[\sum_{k=0}^{\infty}\alpha^kg(x_k,u_k)\right]\)

consider a ‘twin’ stochastic shortest path problem obtained by (i) multiplying all transition probabilities of the original problem by the discount factor \(\alpha\); (ii) adding an extra terminal state \(t\) (zero terminal cost), reachable from every node with prob. \(1-\alpha\); (iii) keeping the same costs \(g(x_k,u_k)\) and zero cost for the terminal state.

Discounted cost as a shortest path

  • The assumptions of the previous slides are satisfied.
  • Applying the same policy to the twin problem, the state evolution is the same until termination of the SP.
  • The expected running cost of the SP is \(g(x_k,u_k)\) times the probability that state \(t\) has not been reached.
  • This probability is \(\alpha^k\), \(0<\alpha<1\), leading to the same expression as for the DC problem.
  • From this link between DC and SP problems we can conclude the results of the next slides.

Value iteration: discounted cost

Algorithm to obtain the optimal value function (cost-to-go), which is the solution to the Bellman equation (see next slide).

Value iteration algorithm

Given any initial conditions \(J_0(1),\dots,J_0(n)\) run the iteration for \(k\in\{0,1,2,\dots\}\)

\[J_{k+1}(i)=\min_{u\in U(i)}\Big[g(i,u)+\alpha\sum_{j=1}^{n}p_{ij}(u)J_k(j)\Big] \qquad i\in\{1,\dots,n\}\]

This will converge to some values \(J^\star(i)\) (solution to the Bellman eq.); thus, one can stop when

\[\max_{i\in\{1,\dots,n\}}|J_{k+1}(i)-J_k(i)|<\epsilon\]

Bellman equation: discounted cost

The values \(J_k(1),\dots,J_k(n)\) of the value iteration algorithm converge to the solution of the Bellman equation. However, this nonlinear equation admits a solution which can also be obtained by other methods.

Theorem

The following set of nonlinear equations

\[J^\star(i)=\min_{u\in U(i)}\Big[g(i,u)+\alpha\sum_{j=1}^{n}p_{ij}(u)J^\star(j)\Big] \qquad i\in\{1,2,\dots,n\} \qquad \text{(Bellman equation)}\]

admits a unique solution.

Optimal policy: discounted cost

The optimal policy can be obtained from the solution to the Bellman equation (since value iteration provides this solution asymptotically, it also provides the optimal policy).

Theorem

The minimiser in the Bellman equation

\[\mu(i)=\underset{u\in U(i)}{\arg\min}\Big[g(i,u)+\alpha\sum_{j=1}^{n}p_{ij}(u)J^\star(j)\Big] \qquad i\in\{1,\dots,n\}\]

where

\[J^\star(i)=\min_{u\in U(i)}\Big[g(i,u)+\alpha\sum_{j=1}^{n}p_{ij}(u)J^\star(j)\Big] \qquad i\in\{1,\dots,n\}\]

is an optimal policy for the discounted cost problem \(x_{k+1}=w_k\), \(p_{ij}(\ell)=\text{Prob}[w_k=j\mid u_k=\ell,\ x_k=i]\).

Example: asset selling

When to accept an offer for an asset, e.g. a car, in order to maximize terminal expected revenue?

Let us consider an infinite horizon version*:

  • Offers at time \(k\), \(\bar w_k\), take values in a finite set, e.g. \(\bar w_0\in\{c_1,c_2,\dots,c_C\}\), \(\text{Prob}[\bar w_0=c_i]=p_i\).
  • The car depreciates at a rate \(\alpha^k\), \(0<\alpha<1\), \(k\) months after the initial time,

\[\bar w_k\in\{\alpha^kc_1,\alpha^kc_2,\dots,\alpha^kc_C\} \quad \text{Prob}[\bar w_k=\alpha^kc_i]=p_i\]

  • There might not be an offer at time \(k\), i.e. \(\sum_{i=1}^{C}p_i=1-p_0\), with \(p_0\) the probability of no offer.

*Unit 2, appendix, considers a different finite horizon version.

Asset selling

Let \(w_k=\dfrac{\bar w_k}{\alpha^k}\) denote a scaled offer, or \(w_k=N\) if there is no offer, and \(u_k\in\{1\ (\text{sell}),\ 0\ (\text{not sell})\}\).

Let \(x_k\), \(k\geq1\), equal the most recent scaled offer, or \(x_k=T\) if the car has been sold. Then

\[x_{k+1}=\begin{cases}T & \text{if } x_k=T, \text{ or if } x_k\neq T \text{ and } u_k=1\ (\text{sell}),\\ w_k & \text{otherwise.}\end{cases}\]

Then we want to find a policy for the sell/not-sell decision that maximises the expected revenue \(\ \mathbb{E}\left[\sum_{k=0}^{\infty}\alpha^kg(x_k,u_k)\right]\) where

\[g(x_k,u_k)=\begin{cases}x_k & \text{if } x_k\neq T \text{ and } u_k=1\ (\text{sell}),\\ 0 & \text{otherwise.}\end{cases}\]

This is a shortest path discounted cost problem (also a stopping time problem). The infinite horizon framework is an abstraction (or approximation) of the more realistic case that the car will be sold within a (large but finite) horizon.

Asset selling: value iteration

Value iteration takes the form \(J_k(N)=0\), \(J_k(T)=0\),

\[J_{k+1}(x_k)=\max\Big\{x_k,\ \alpha\sum_{i=1}^{C}p_iJ_k(c_i)\Big\}, \qquad x_k\neq N,\ x_k\neq T\]

Considering \(c_i=10000+(i-1)100\) euros, \(C=101\), \(p_i=e^{-\frac{(c_i-\bar c)^2}{2\bar v}}\), \(\bar c=15000\), \(\bar v=2000^2\):

Asset selling: optimal policy

Accordingly, the policy also converges to an optimal policy which is stationary (it does not depend on time!) and simple to explain: sell if the scaled offer is larger than around \(16700\), do not sell otherwise.

Q-factors

  • So far we have worked with the following cost functions and optimal cost functions

\[\textbf{SP:}\quad J^\star(i)=\min_\mu J_\mu(i) \qquad\qquad \textbf{DC:}\quad J^\star(i)=\min_\mu J_\mu(i)\]

These are also called value functions and play the role of costs-to-go in infinite horizon problems.

  • We can however write the algorithms we have seen in terms of Q-factors and optimal Q-factors

\[\textbf{SP:}\quad Q_\mu(i,u)=g(i,u)+\sum_{j=1}^{n}p_{ij}(u)J_\mu(j) \qquad Q^\star(i,u)=g(i,u)+\sum_{j=1}^{n}p_{ij}(u)J^\star(j)\]

\[\textbf{DC:}\quad Q_\mu(i,u)=g(i,u)+\alpha\sum_{j=1}^{n}p_{ij}(u)J_\mu(j) \qquad Q^\star(i,u)=g(i,u)+\alpha\sum_{j=1}^{n}p_{ij}(u)J^\star(j)\]

  • Note that cost functions are defined on the state space and Q-factors on the state/control space.
  • Doing so when there is a model (\(p_{ij}(u)\) are known) brings no advantages, but it is important in model-free settings.

Q-Learning (discounted cost)

Consider an infinitely long (in practice sufficiently long) simulation for an arbitrary policy, i.e. a sequence of state-control pairs \((x_t,u_t)\), \(t\in\{0,1,2,\dots\}\). For each state-control pair \((i,u)\) define Q-factors \(Q(i,u)\) and estimates at time \(t\) by \(Q_t(i,u)\). The Q-factor estimate pertaining to the state-control pair \((i,u)=(x_t,u_t)\) is updated at time \(t\) according to

\[Q_{t+1}(x_t,u_t)=\big(1-\gamma^t\big)Q_t(x_t,u_t)+\gamma^t\Big(g(x_t,u_t)+\alpha\min_{v\in U(x_{t+1})}Q_t(x_{t+1},v)\Big)\]

where \(\gamma^t\in(0,1]\) are arbitrary.

All the other Q-factor estimates remain unchanged (\(Q_{t+1}(i,j)=Q_t(i,j)\), \((i,j)\neq(x_t,u_t)\)).

Discussion

  • Q-learning is one of the first and most famous RL methods, proposed in 1989*.
  • At each step it takes a weighted average with the previous estimate and the target

\[Q_{t+1}(x_t,u_t)=\big(1-\gamma^t\big)\underbrace{Q_t(x_t,u_t)}_{\text{previous estimate}}+\gamma^t\underbrace{\Big(g(x_t,u_t)+\alpha\min_{v\in U(x_{t+1})}Q_t(x_{t+1},v)\Big)}_{\text{target}}\]

The goal is that the Q-factor estimate gets closer to (and converges to) the target.

  • See the resemblance with value iteration: \(\ Q_{k+1}(x_k,u_k)=g(x_k,u_k)+\alpha\min\limits_{v\in U(x_{k+1})}Q_k(x_{k+1},v)\).
  • Here the simulation is a single infinitely long one, but we could run several (infinitely many) finite-length simulations instead and concatenate them.
  • The step size is free; a constant step size is often chosen but does not lead to convergence; for this it should decrease to zero in a special way, as discussed next.
  • The policy used to generate the data is called the exploration policy, and for Q-learning it is arbitrary. The target policy is the one we wish to learn (typically the optimal policy).

*Watkins, Learning from delayed rewards, PhD thesis, Cambridge University, 1989.

Stochastic approximation

Consider a sequence of independent and identically distributed random variables \((r_1,r_2,r_3,\dots)\) for which we wish to determine the mean, denoted by \(\mu\). To this effect, consider the recursion

\[z_{t+1}=(1-\gamma^t)z_t+\gamma^tr_t\]

If

\[\gamma^t>0 \qquad\qquad \sum_{t=0}^{\infty}\gamma^t=\infty \qquad\qquad \sum_{t=0}^{\infty}(\gamma^t)^2<\infty\]

Then

\[\lim_{t\to\infty}z_t=\mu\]

Stochastic approximation

  • The incremental sample mean \(\ \frac{1}{t}\left(\sum_{\ell=1}^{t}r_\ell\right)\ \) can be written in such a form, \(\ z_{t+1}=\left(1-\frac{1}{t}\right)z_t+\frac{1}{t}r_t\).
  • It works well when the distribution of \(r_t\) does not change, see left figure.
  • When the distribution does change, picking constant values adapts better (right figure).
  • The trade-off is present when \(\gamma\) is constant: small \(\gamma\) is accurate in steady state but slow.

Q-Learning (shortest path)

Consider infinitely many (in practice sufficiently many) simulations \(s\in\{1,2,\dots\}\) for an arbitrary policy, i.e. sequences of state-control pairs \((x_k^s,u_k^s)\), \(k\in\{0,1,2,\dots,K^s\}\), with \(K^s\) the time at which the terminal state of simulation \(s\) is reached. Index the state-control pairs as

\[\{(x_t,u_t)\mid t\in\mathbb{N}\cup\{0\}\}=\big((x_0^1,u_0^1),\dots,(x_{K^1}^1,u_{K^1}^1),(x_0^2,u_0^2),\dots,(x_{K^2}^2,u_{K^2}^2),(x_0^3,u_0^3),\dots\big)\]

For each state-control pair define Q-factors \(Q(i,u)\) and estimates at update time \(t\) by \(Q_t(i,u)\). The Q-factor estimate pertaining to the state-control pair \((i,u)=(x_t,u_t)\) is updated at index \(t\neq K^s\) according to

\[Q_{t+1}(x_t,u_t)=\big(1-\gamma^t\big)Q_t(x_t,u_t)+\gamma^t\Big(g(x_t,u_t)+\min_{v\in U(x_{t+1})}Q_t(x_{t+1},v)\Big)\]

where \(\gamma^t\in(0,1]\) are arbitrary.

All the other Q-factor estimates remain unchanged (\(Q_{t+1}(i,j)=Q_t(i,j)\), \((i,j)\neq(x_t,u_t)\)).

Convergence

Theorem (discounted cost)

The Q-factors of the Q-Learning algorithm converge to the optimal ones if

  • all the state-control pairs are generated in the simulation infinitely often;
  • the step size satisfies

\[\gamma^t>0 \qquad\qquad \sum_{t=0}^{\infty}\gamma^t=\infty \qquad\qquad \sum_{t=0}^{\infty}(\gamma^t)^2<\infty\]

  • Note that once the optimal Q-factors \(Q^\star(i,u)\) are known, obtaining the optimal policy is trivial: \(\ \mu(i)=\underset{u\in U(i)}{\arg\min}Q^\star(i,u)\).
  • A similar result can be obtained for the shortest path case. Actually, we argue now that the result is easy to obtain for finite horizon problems (a special case of shortest path).
  • For discounted cost problems it needs additional mathematical arguments.
  • We first specialise the Q-learning algorithm for shortest path problems to finite-horizon problems.

Q-Learning (finite horizon)

Consider a finite horizon optimal control problem with unknown model

\[\min_{u_k=\mu_k(x_k)}\mathbb{E}\left[\sum_{k=0}^{h-1}g_k(x_k,u_k)+g_h(x_h)\right] \qquad x_{k+1}=f_k(x_k,u_k,w_k)\]

Consider infinitely many simulations \(s\in\{1,2,\dots\}\) for an arbitrary policy, i.e. sequences of state-control pairs \((x_k^s,u_k^s)\), \(k\in\{0,1,2,\dots,h\}\) (note that \(u_h^s\) is irrelevant), indexed as before. For each stage-state-control triple define Q-factors \(Q(k,i,u)\) and estimates \(Q_t(k,i,u)\) at update \(t\). The estimate pertaining to \((k,x_t,u_t)\) is updated as

\[Q_{t+1}(k,x_t,u_t)=\big(1-\gamma^t\big)Q_t(k,x_t,u_t)+\gamma^t\Big(g_k(x_t,u_t)+\min_{v\in U(x_{t+1})}Q_t(k+1,x_{t+1},v)\Big) \quad k\neq h-1\]

\[Q_{t+1}(h-1,x_t,u_t)=\big(1-\gamma^t\big)Q_t(h-1,x_t,u_t)+\gamma^t\big(g_{h-1}(x_t,u_t)+g_h(x_{t+1})\big) \quad k=h-1\]

where \(\gamma^t\in(0,1]\) are arbitrary. All other Q-factor estimates remain unchanged.

Convergence: finite-horizon problems

Step 1. Consider an arbitrary state-control pair \((x_{h-1},u_{h-1})=(i,u)\) at the terminal decision stage \(h-1\). By assumption this state-control pair will be visited infinitely often, and when it is visited its Q-factor is updated according to

\[Q_{t+1}(h-1,i,u)=\big(1-\gamma^t\big)Q_t(h-1,i,u)+\gamma^t\big(g_{h-1}(i,u)+g_h(f(i,u,\underbrace{w_{h-1}}_{\text{disturbance r.v.}}))\big)\]

Then, using the stochastic approximation result, eventually \(Q_t(h-1,i,u)\) converges to \(g_{h-1}(i,u)+\mathbb{E}\left[g_h(f(i,u,w_{h-1}))\right]\).

Step 2. Consider now \(t\) very large, such that \(Q_t(h-1,i,u)\) has converged for every \((i,u)\). Then

\[\tilde J_{h-1}(x_{h-1})=\min_{v\in U(x_{h-1})}Q_t(h-1,x_{h-1},v)=\min_{v\in U(x_{h-1})}g_{h-1}(x_{h-1},v)+\mathbb{E}\left[g_h(f(x_{h-1},v,w_{h-1}))\right]\]

is the optimal cost-to-go, and plays the role of terminal cost from the point of view of stage \(h-2\).

Convergence: finite-horizon problems

Step 3. Consider an arbitrary state-control pair \((x_{h-2},u_{h-2})=(i,u)\) at stage \(h-2\). By assumption this state-control pair will be visited infinitely often, and when it is visited its Q-factor is updated according to

\[Q_{t+1}(h-2,i,u)=\big(1-\gamma^t\big)Q_t(h-2,i,u)+\gamma^t\Big(g_{h-2}(i,u)+\underbrace{\min_v Q_t(h-1,f(i,u,w_k),v)}_{\tilde J_{h-1}(f(i,u,w_k))\ \text{-- see Step 2}}\Big)\]

Following the same arguments as in Steps 1 and 2, we conclude that \(Q_t(h-2,i,u)\) will converge, for large \(t\), to the optimal values.

Step 4. We can follow the same steps for all the other stages (\(h-3\), \(h-4\), …) and conclude that \(Q_t(k,i,u)\) converges to the optimal values for all \((k,i,u)\).

Discussion

This result is bittersweet:

  • It is very reassuring that for any Markov decision problem in discrete time (and in continuous time by proper discretization) Q-learning will solve it without the need for a model.
  • However, Q-learning is often data inefficient. ‘Sufficiently large iterations’ in the proof typically means a tremendous amount of simulations even for simple problems.
  • There are methods that are more data efficient even though they do not guarantee optimality.

Conclusion: while the result is interesting, the two curses – dimensionality, and the need for a great many simulations (data) – are not solved by Q-learning.

Concluding remarks

To summarize:

  • Reinforcement learning asks the same question as Part I of the course – find a policy minimising an additive cost – but without a model: only the system itself, or a simulator, is available.
  • Infinite-horizon formulations are the natural setting: policies become time-invariant. Four variants exist (undiscounted, stochastic shortest path, discounted, average cost); the discounted problem is a shortest path problem in disguise, and a finite-horizon problem is one too, by augmenting the state with time.
  • For both, value iteration converges to the unique solution of a Bellman equation, and the minimiser of that equation is an optimal policy.
  • Writing the same algorithms in terms of Q-factors buys nothing when the model is known – but it is what makes a model-free algorithm possible, because a Q-factor can be updated from a single observed transition.
  • Q-learning does exactly that, and converges to the optimal Q-factors under two conditions: every state-control pair is visited infinitely often, and the step size satisfies the stochastic approximation conditions.
  • The guarantee is strong and the practice is hard: the method is correct but data hungry, and it does nothing about the curse of dimensionality. The remaining units of Part II are about what to do instead.

Average cost problems

Decomposing the cost

  • We need the following technical assumption: there is one state, by convention state \(n\), for which there is a positive probability that it is visited in a finite number of initial stages.
  • Then state \(n\) is recurrent, meaning that eventually the system will return to it.
  • Let \(s_\ell\) be the times at which the state is \(n\), and suppose there are \(L+1\) of them in \(\{0,1,\dots,T-1\}\).
  • Average cost \(J(i)=\lim\limits_{T\to\infty}\frac{1}{T}J_T(i)\), with \(J_T(i)=\mathbb{E}\left[\sum_{k=0}^{T-1}g(x_k,\mu(x_k))\mid x_0=i\right]\) partitioned as

\[J_T(i)=\underbrace{\mathbb{E}\left[\sum_{k=0}^{s_0-1}g\mid x_0=i\right]}_{\text{(1)}}+\underbrace{\sum_{\ell=0}^{L-1}\mathbb{E}\left[\sum_{k=s_\ell}^{s_{\ell+1}-1}g\mid x_{s_\ell}=n\right]}_{\text{(2)}}+\underbrace{\mathbb{E}\left[\sum_{k=s_L}^{T-1}g\mid x_{s_L}=n\right]}_{\text{(3)}}\]

Implications

  • When taking the limit \(J(i)=\lim_{T\to\infty}\frac{1}{T}J_T(i)\), terms (1) and (3) will not contribute to the cost.
  • The second term will be a summation of \(L\) (number of returns) identical terms, so that

\[J(i)=\lim_{T\to\infty}\frac{L}{T}\mathbb{E}\left[\sum_{k=s_0}^{s_1-1}g(x_k,\mu(x_k))\mid x_{s_0}=n\right]=\frac{1}{\mathbb{E}[s_1-s_0]}\mathbb{E}\left[\sum_{k=s_0}^{s_1-1}g(x_k,\mu(x_k))\mid x_{s_0}=n\right]\]

  • This partition has three implications:
      1. the average cost does not depend on the initial state: for any policy \(\mu\) it is the same for any initial condition, \(J(i)=\lambda_\mu\) for every \(i\);
      1. the average cost only depends on what happens between two visits to state \(n\);
      1. this average cost can be written, for a given policy \(\mu\), as

\[\lambda_\mu=\frac{C_{nn}(\mu)}{N_{nn}(\mu)} \qquad \begin{aligned}&C_{nn}(\mu)\ \text{-- expected cost from } n \text{ up to the first return to } n\\ &N_{nn}(\mu)=\tfrac{T}{L}\ \text{-- expected number of stages to return}\end{aligned}\]

  • Related to (ii) and (iii), the average cost can be computed from a shortest path problem with initial state \(n\), as we show next.

Average cost as a shortest path

  • We want to consider a shortest path problem which starts in state \(n\) and ends in state \(n\). However, care is needed, since the transitions from a terminal state must only include itself.
  • Therefore we introduce a special terminal state \(t\) such that the destination of all out-going transitions from any state to state \(n\) is changed to \(t\), with the same probabilities.
  • The cost from the original graph \(g(i,u)\) is modified to \(g(i,u)-\lambda^\star\), where

\[\lambda^\star=\min_\mu\lambda_\mu=\min_\mu\frac{C_{nn}(\mu)}{N_{nn}(\mu)}=\min_\mu\frac{1}{\mathbb{E}[s_1-s_0]}\mathbb{E}\left[\sum_{k=s_0}^{s_1-1}g(x_k,\mu(x_k))\mid x_{s_0}=n\right]\]

Average cost as a shortest path

Why choose these costs? Note that if \(\mu^\star\) is the optimal policy, \(\lambda^\star=\frac{C_{nn}(\mu^\star)}{N_{nn}(\mu^\star)}\) and \(\lambda_\mu=\frac{C_{nn}(\mu)}{N_{nn}(\mu)}\geq\lambda^\star\). Thus

\[C_{nn}(\mu)-\lambda^\star N_{nn}(\mu)\geq0 \qquad \text{with equality when } \mu=\mu^\star.\]

  • The optimal policy can then be found by solving \(\ \min_\mu\ C_{nn}(\mu)-\lambda^\star N_{nn}(\mu)\).
  • But this is nothing more than the shortest path problem just formulated, since

\[\min_\mu\mathbb{E}\left[\sum_{k=s_0}^{s_1-1}\big(g(x_k,\mu(x_k))-\lambda^\star\big)\mid x_{s_0}=n\right]=\min_\mu\ \underbrace{C_{nn}(\mu)}_{}-\lambda^\star\underbrace{\mathbb{E}[s_1-s_0]}_{N_{nn}(\mu)}\]

Bellman equation: average cost

  • The Bellman equation for the shortest path problem is

\[h^\star(i)=\min_{u\in U(i)}\Big[g(i,u)-\lambda^\star+\sum_{j=1}^{n-1}p_{ij}(u)h^\star(j)\Big]\]

since in the shortest path problem the transition probability from \(i\) to \(j\) is \(p_{ij}(u)\) and the transition probability from \(i\) to \(n\) is zero.

  • We also have that \(h^\star(n)=C_{nn}(\mu^\star)-\lambda^\star N_{nn}(\mu^\star)=0\), so that we can also write

\[h^\star(i)=\min_{u\in U(i)}\Big[g(i,u)-\lambda^\star+\sum_{j=1}^{n}p_{ij}(u)h^\star(j)\Big]\]

Theorem

The optimal average cost \(\lambda^\star\) is the same for all initial states and, together with some vector \((h^\star(1),\dots,h^\star(n))\), satisfies

\[\lambda^\star+h^\star(i)=\min_{u\in U(i)}\Big[g(i,u)+\sum_{j=1}^{n}p_{ij}(u)h^\star(j)\Big] \qquad i\in\{1,2,\dots,n\} \qquad \text{(Bellman equation)}\]

with \(h^\star(n)=0\).

Numerical method, optimal policy

Numerical method to obtain the optimal vector \((h^\star(1),\dots,h^\star(n))\) and the optimal policy:

Step 1. Run value iteration

\[J_{k+1}(i)=\min_{u\in U(i)}\Big[g(i,u)+\sum_{j=1}^{n}p_{ij}(u)J_k(j)\Big]\]

and compute \(\ \lim\limits_{k\to\infty}\dfrac{J_k(i)}{k}=\lambda^\star\).

Step 2. Solve the shortest path problem of the previous slides with value iteration.
