Recap: approaches in reinforcement learning

Approximation in value space

Approximate the optimal cost-to-go \(J^\star_{k+1}\) by some other cost \(\tilde J_{k+1}\) and use the policy

\[u_k=\arg\min_{u_k\in U_k(x_k)}\mathbb{E}\big[g_k(x_k,u_k,w_k)+\tilde J_{k+1}(f_k(x_k,u_k,w_k))\big]\]

(this is for a one-step lookahead horizon; there are also multistep variants). Last lectures: deep Q-learning, simulation-based policy iteration, SARSA, semi-gradient, LSTD.

Approximation in control/policy space

Select the policy from a parameterized class of policies – a state feedback, a neural network,

\[u_k=\mu_k(x_k,r_k), \qquad r_k \ \text{the parameters}\]

This involves a search in the parameter space, the utility of each parameter being assessed by simulation. Today: policy gradient methods.

Approximation in value and policy space

A combination of the two. Today: actor-critic methods.

Parameterizing a policy

Let us start with problems with finite state and input spaces.

  • For deterministic policies the cost is a discontinuous function of the policy – so the only option is exhaustive search.
  • For stochastic policies it is often a continuously differentiable function – so we can use gradient search.

Parameterizing a policy

The stochastic policy can be parameterized in any way, as long as it is differentiable with respect to its parameters. We write, for the probability of an input \(\underline{u}\) being selected at state \(\underline{x}\),

\[\pi(\underline u\mid\underline x,\theta)=\text{Prob}[u_k=\underline u\mid x_k=\underline x] \qquad \text{(discrete control and state spaces)}\]

\[\text{Prob}[u_k\in A\mid x_k=\underline x]=\int_A\pi(\underline u\mid\underline x,\theta)\,d\underline u \qquad \text{(continuous control and state spaces)}\]

If the state and control input spaces are discrete, a common way is to assign preferences, captured by \(h(\underline x,\underline u,\theta)\). Based on these preferences a so-called exponential soft-max stochastic policy can be built as

\[\pi(\underline u\mid\underline x,\theta)=\frac{e^{h(\underline x,\underline u,\theta)}}{\sum_b e^{h(\underline x,b,\theta)}}\]

Idea behind policy gradient

Parameterize the policy in terms of \(\pi(\underline u\mid\underline x,\theta)\). Then the cost can be written as a differentiable function of the parameters,

\[J(\theta)=\mathbb{E}_{\pi_\theta}[C],\]

with

\[\textbf{Finite horizon}\qquad C=\mathbb{E}_{w_k}\Big[\sum_{k=0}^{h-1}g(x_k,u_k)+g_h(x_h)\Big]\]

\[\textbf{Infinite horizon, discounted}\qquad C=\mathbb{E}_{w_k}\Big[\sum_{k=0}^{\infty}\alpha^kg(x_k,u_k)\Big]\]

Directly optimize the policy by gradient descent,

\[\theta_{k+1}=\theta_k-\gamma\nabla_\theta J(\theta_k).\]

We need a method to compute this gradient.

Policy gradient theorem

The policy gradient theorem allows us to compute \(\nabla_\theta J(\theta)\). It states that this gradient is proportional to

\[\nabla_\theta J(\theta)\propto\sum_{\underline x}\mu(\underline x)\sum_{\underline u}Q_\pi(\underline x,\underline u)\,\nabla_\theta\pi(\underline u\mid\underline x,\theta)\]

where

\[\mu(\underline x)=\text{Prob}[x_k=\underline x] \qquad \text{(in finite-horizon problems the state includes time)}\]

and \(Q_\pi(\underline x,\underline u)\) is the Q-factor when the policy \(\pi(\underline u\mid\underline x,\theta)\) is used.

Note the shape of the expression: the gradient of the cost is written in terms of the gradient of the policy, and the model appears nowhere. To make this a data-based method we still need the gradient to be estimated from data.

Example

Here we can write an explicit formula for the cost as a function of the parameter \(\theta\):

\[J_0(1)=\tfrac12\big(1+6+1+\tfrac22+\tfrac12\big)+\tfrac12\Big(3+\theta\big(2+1+\tfrac22+\tfrac12\big)+(1-\theta)\big(1+\theta^2(2+\tfrac22+\tfrac12)+(1-\theta^2)(5+\tfrac42+\tfrac32)\big)\Big)\]

Taking the state to be the pair (stage \(k\), state at stage \(k\)),

\[\mu((1,2))=\tfrac12, \qquad Q((1,2),1)=\tfrac92, \qquad Q((2,2),1)=\tfrac72\]

\[\mu((2,2))=\tfrac12(1-\theta), \qquad Q((1,2),2)=1+\theta^2\tfrac72+(1-\theta^2)\tfrac{17}{2}, \qquad Q((2,2),2)=\tfrac{17}{2}\]

Example

Taking the gradient we obtain an expression confirming the one given by the policy gradient theorem.

\[J_0(1)=\tfrac{25}{4}+\tfrac12\big(3+\tfrac92\theta\big)+\tfrac12(1-\theta)\Big(1+\tfrac72\theta^2+\tfrac{17}{2}\big(1-\theta^2\big)\Big)\]

Each brace is one factor of the policy gradient theorem: a state probability \(\mu\), a Q-factor, and the gradient of the policy.

Intermezzo: stochastic gradient descent

For problems that involve the gradient of an expected value of a cost function over some stochastic variable \(w\) – or the expected value of a gradient of a cost –

\[\theta_{k+1}=\theta_k-\gamma\nabla_\theta\mathbb{E}_w\big[V(\theta,w)\big],\]

stochastic gradient methods simply replace the expected value by a realization of \(w\),

\[\theta_{k+1}=\theta_k-\gamma\nabla_\theta V(\theta,w).\]

When \(V\) is convex, this method converges to the optimal value of the parameter.

(The same intermezzo appeared in Unit 12; it is repeated because both of this unit’s algorithms are instances of it.)

Data-based implementation: all actions

Analyzing again the expression for the gradient,

\[\nabla_\theta J(\theta_k)\propto\sum_{\underline x}\mu(\underline x)\sum_{\underline u}Q_\pi(\underline x,\underline u)\,\nabla_\theta\pi(\underline u\mid\underline x,\theta_k), \qquad \mu(\underline x)=\text{Prob}[x_k=\underline x],\]

we notice that the outer sum is an expectation over the states the policy visits,

\[\nabla_\theta J(\theta_k)\propto\mathbb{E}_\mu\Big[\sum_{\underline u}Q_\pi(x_k,\underline u)\,\nabla_\theta\pi(\underline u\mid x_k,\theta_k)\Big].\]

Replacing expected values by sampled values gives a stochastic gradient method,

\[\theta_{k+1}=\theta_k-\gamma\sum_{\underline u}Q_\pi(x_k,\underline u)\,\nabla_\theta\pi(\underline u\mid x_k,\theta_k).\]

This is called the all actions method.

Data-based implementation: REINFORCE

  • The previous method is completely fine, but different from REINFORCE, which is more popular.
  • REINFORCE replaces the summation over actions by the action actually taken.
  • It builds on a similar trick, dividing and multiplying by the probability of taking the action:

\[\nabla_\theta J(\theta_k)\propto\mathbb{E}_\mu\Big[\sum_{\underline u}Q_\pi(x_k,\underline u)\nabla_\theta\pi(\underline u\mid x_k,\theta_k)\Big]=\mathbb{E}_\mu\Big[\sum_{\underline u}\pi(u_k\mid x_k,\theta_k)\,Q_\pi(x_k,\underline u)\frac{\nabla_\theta\pi(u_k\mid x_k,\theta_k)}{\pi(u_k\mid x_k,\theta_k)}\Big]\]

\[=\mathbb{E}_\mu\mathbb{E}_\pi\Big[Q_\pi(x_k,\underline u)\frac{\nabla_\theta\pi(u_k\mid x_k,\theta_k)}{\pi(u_k\mid x_k,\theta_k)}\Big]\]

Besides, \(Q_\pi(x_k,u_k)\) is replaced by the cost obtained by Monte-Carlo sampling after applying \(u_k\) at state \(x_k\), denoted \(G_k\). Replacing expected values by sampled ones,

\[\theta_{k+1}=\theta_k-\gamma\,G_k\,\frac{\nabla_\theta\pi(u_k\mid x_k,\theta_k)}{\pi(u_k\mid x_k,\theta_k)}.\]

This is the REINFORCE method.

REINFORCE

Algorithm

For each Monte-Carlo run:

  • Initialize \(x_0\) randomly, apply \(\pi(\underline u\mid\underline x,\theta)\), and obtain \(\big((x_0,u_0),(x_1,u_1),\dots,(x_{h-1},u_{h-1}),x_h\big)\).
  • For each \(k\in\{0,1,\dots,h-1\}\) compute

\[\theta_{k+1}=\theta_k-\gamma\,G_k\,\frac{\nabla_\theta\pi(u_k\mid x_k,\theta_k)}{\pi(u_k\mid x_k,\theta_k)}, \qquad G_k=\sum_{t=k}^{h-1}g(x_t,u_t)+g_h(x_h).\]

Often it is equivalently written as

\[\theta_{k+1}=\theta_k-\gamma\,G_k\,\nabla_\theta\log\big(\pi(u_k\mid x_k,\theta_k)\big),\]

since \(\nabla_\theta\log\pi=\nabla_\theta\pi/\pi\).

Pros and cons

Pros

  • Works well with continuous action spaces.
  • Can model stochastic policies.

Cons

  • High variance in the gradient estimation.
  • Requires careful tuning of learning rates.

Baseline subtraction

Suppose a comparison function to the Q-factor is added in the equation

\[\nabla_\theta J(\theta_k)\propto\sum_{\underline x}\mu(\underline x)\sum_{\underline u}\big(Q_\pi(\underline x,\underline u)-b(\underline x)\big)\nabla_\theta\pi(\underline u\mid\underline x,\theta_k)\]

We can add such a term since it cancels out and has no effect on the gradient:

\[-b(\underline x)\sum_{\underline u}\nabla_\theta\pi(\underline u\mid\underline x,\theta_k)=-b(\underline x)\nabla_\theta\Big(\sum_{\underline u}\pi(\underline u\mid\underline x,\theta_k)\Big)=-b(\underline x)\nabla_\theta(1)=0\]

Following similar steps as before we arrive at the update rule to be used in the REINFORCE algorithm,

\[\theta_{k+1}=\theta_k-\gamma\big(G_k-b(x_k)\big)\frac{\nabla_\theta\pi(u_k\mid x_k,\theta_k)}{\pi(u_k\mid x_k,\theta_k)}.\]

By properly picking \(b(\underline x)\), baseline subtraction is a variance reduction technique – while it would not matter for the expression above, it does influence the REINFORCE method significantly. In fact, actor-critic methods can be interpreted as baseline subtraction.

Motivation

Value-based methods

  • Efficient, but struggle with continuous actions (e.g. Q-learning).

Policy-based methods

  • Handle continuous actions, but suffer from high variance (e.g. REINFORCE).

Actor-critic

  • Combines the strengths of both approaches.

Main idea

Actor

  • Learns the policy \(\pi(\underline u\mid\underline x,\theta)\) to select actions.

Critic

  • Estimates the cost function, to criticize the actor’s decisions – this is achieved through the baseline.

Policy update

  • Guided by the critic’s feedback, to improve decision-making.

Main idea

In the REINFORCE method, pick the baseline to be a cost approximation obtained by a critic,

\[b(x_k)\ \longrightarrow\ \hat J(x_k,\alpha_k),\]

for some weights \(\alpha_k\) to be learned online by a neural network. (Note: \(\alpha_k\) here denotes the critic’s weight vector, not the discount factor.)

Two ways to learn the weights \(\alpha_k\):

\[\alpha_{k+1}=\alpha_k-\beta\big(G_k-\hat J(x_k,\alpha_k)\big)\nabla_{\alpha_k}\hat J(x_k,\alpha_k)\]

or

\[\alpha_{k+1}=\alpha_k-\beta\big(g(x_k,u_k)+\hat J(x_{k+1},\alpha_{k+1})-\hat J(x_k,\alpha_k)\big)\nabla_{\alpha_k}\hat J(x_k,\alpha_k),\]

where \(g(x_k,u_k)+\hat J(x_{k+1},\alpha_{k+1})\) is an estimate of \(G_k\). The first is Monte-Carlo, the second is TD – the Unit 11 choice, reappearing inside the critic.

The most popular version of the actor-critic method also replaces \(G_k\) by \(g(x_k,u_k)+\hat J(x_{k+1},\alpha_{k+1})\) in the policy gradient step, and is given next.

Actor-critic

Algorithm

For each Monte-Carlo run:

  • Initialize \(x_0\) randomly, apply \(\pi(\underline u\mid\underline x,\theta)\), and obtain \(\big((x_0,u_0),(x_1,u_1),\dots,(x_{h-1},u_{h-1}),x_h\big)\).
  • For each \(k\in\{0,1,\dots,h-1\}\) compute

\[\textbf{critic}\qquad \alpha_{k+1}=\alpha_k-\beta\big(g(x_k,u_k)+\hat J(x_{k+1},\alpha_{k+1})-\hat J(x_k,\alpha_k)\big)\nabla_{\alpha_k}\hat J(x_k,\alpha_k)\]

\[\textbf{actor}\qquad \theta_{k+1}=\theta_k-\gamma\Big(g(x_k,u_k)+\hat J(x_{k+1},\alpha_{k+1})-\hat J(x_k,\alpha_k)\Big)\frac{\nabla_\theta\pi(u_k\mid x_k,\theta_k)}{\pi(u_k\mid x_k,\theta_k)}\]

The bracket is the same quantity in both lines: the temporal difference of Unit 11. The critic uses it to improve its own estimate; the actor uses it as the signed weight on the policy gradient.

Variants

A2C (Advantage Actor-Critic) – uses the advantage function to reduce variance.

A3C (Asynchronous Advantage Actor-Critic) – runs multiple agents in parallel.

DDPG (Deep Deterministic Policy Gradient) – for deterministic policies in continuous spaces.

PPO (Proximal Policy Optimization) – stable and efficient policy updates.

SAC (Soft Actor-Critic) – adds entropy regularization for exploration.

Mountain car example

A car placed stochastically at the bottom of a sinusoidal valley, with the only possible actions being the accelerations that can be applied to the car in either direction.

Goal: accelerate the car to reach the goal state on top of the right hill.

Observations: position and velocity of the car, both continuous.

Action space: acceleration, continuous.

Reward: a negative reward of \(-0.1\times\text{action}^2\) at each timestep, penalising large-magnitude actions; a positive reward of \(+100\) if the car reaches the goal.

Concluding remarks

Policy gradient methods

  • Require the policy to be stochastic, so that the cost is a differentiable function of the parameters. For a deterministic policy over a finite action set the cost is piecewise constant, and there is nothing to differentiate.
  • Build on the policy gradient theorem, which expresses the gradient of the cost in terms of the gradient of the policy – and in which the model does not appear.
  • REINFORCE is a stochastic-gradient version of policy gradient descent, built on that theorem, with the Q-factor replaced by a Monte-Carlo return and the sum over actions replaced by the action actually taken.
  • The price is variance. The Monte-Carlo return is an unbiased but noisy estimate, and the importance-like ratio \(\nabla_\theta\pi/\pi\) multiplies that noise.

Actor-critic methods

  • Can be seen as a way to reduce the variance of policy gradient methods, by subtracting a baseline that does not change the gradient in expectation.
  • Taking that baseline to be a learned cost approximation gives the critic; the policy is the actor. The quantity passed from one to the other is the temporal difference of Unit 11.
  • This is the combination promised at the start of the course: approximation in value space and in policy space at the same time.
