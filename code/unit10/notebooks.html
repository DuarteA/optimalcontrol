1 Asset selling: value iteration

The worked example of the unit’s discounted-cost section. Offers for a used car arrive month by month, the car depreciates, and the question is when to accept. Value iteration collapses to one comparison per state – take what is on the table, or hold out for the discounted expected value of waiting – and the optimal policy is a stationary threshold rule. The notebook reproduces the two figures in the unit and then runs the iteration to convergence, which the figures do not: the tenth iterate plotted in the lecture has a threshold of about \(16\,700\) euros, while the converged policy sells above \(16\,900\).

Download A_10_AssetSellingValueIteration.ipynb

2 Stopping time: the same problem, learned

The asset selling problem solved again with no model – the offer distribution is never used, only sampled. Because the only decision is when to stop, the value function collapses to a single number, so this is the smallest possible setting in which to watch learning work. It is done twice: once as the plain stochastic approximation recursion of the unit, and once as Q-learning driven by an arbitrary exploration policy (a random buyer who accepts more readily as the offer rises). Both land on the value iteration answer. Both need hundreds of thousands of samples to do it.

Download A_10_stoppingtimeQLearning.ipynb

3 Stochastic inventory control by Q-learning

Unit 2’s inventory problem, learned instead of solved. The state is the pair (stock, stage) flattened into one index – the state augmentation that turns a finite-horizon problem into a shortest path problem – after which the stationary Q-learning driver applies unchanged. The notebook ends by computing the exact dynamic programming solution and subtracting: stage 0 agrees to a few hundredths, the last stage is exact, and five entries are still at zero because those states are never visited. That last column of the error table is the convergence theorem’s “every state-action pair infinitely often” condition failing in front of you.

Download A_10_StochInventoryControlQLearning.ipynb

4 State and input discretization by Q-learning

Unit 7’s minimum-energy double integrator, on the same discretized grid, without the grid dynamics being given to the learner. The problem is deterministic, so the step size can be \(1\) and every update is exact; it is also a finite-horizon problem with a hard terminal constraint, so it uses the stage-indexed driver, with an infinite Q-factor for any action that misses the target. It recovers Unit 7’s answer exactly – \(u=[4,-4]\), cost \(16\) – which is the cleanest demonstration in the unit that Q-learning is dynamic programming with sampling in place of expectation.

Download A_10_statediscQLearning.ipynb

5 Robot path planning by Q-learning

The grid path planning problem of Units 2 and 3: a robot crosses a \(13\times14\) maze with noisy motion, commanded up, straight or down. The agent is given no map and no slip probabilities, only a simulator. Thirty thousand simulated crossings put the learned cost-to-go within a few tenths of exact stochastic dynamic programming, and the two agree on the best row to start from. The errors are largest exactly where the robot rarely goes.
